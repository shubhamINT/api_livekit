# Spec checklist

Run before planning. Every box ticked, or the spec goes back to the user.

- [ ] No `[NEEDS CLARIFICATION]` marker remains.
- [ ] Every acceptance criterion is numbered, testable, and measurable.
- [ ] No criterion names a framework, library, table, or file.
- [ ] Error cases and limits are stated, not implied.
- [ ] Who may call it and see what is stated.
- [ ] Out of scope is filled in.
- [ ] Change log has a row for this task.
- [ ] The user has read and approved the spec.
