# Agent tracking

Working notes for multi-PR efforts driven by a coding agent. One file per effort, named
after the effort. Each file carries the same three sections so progress is readable at a
glance:

- **Doing now** — the single step in progress.
- **Done** — what has landed, newest last.
- **Left** — everything still ahead, in order.

Update the file as part of the work, not afterwards. If a step changes shape mid-flight,
edit the plan before writing the code.
