Standalone Voice Endpoints (STT, TTS, LLM)

Task 2026-11-08-feature-standalone-voice-endpoints · spec 002 · verdict Converged · nothing committed

Outcome

Standalone modular REST endpoints have been implemented under FastAPI for Speech-to-Text (POST /stt/transcribe), Text-to-Speech (POST /tts/synthesize), and Chat Completions (POST /llm/chat). They support direct parameters as well as assistant configuration inheritance. Direct async HTTP clients in src/services/{stt,tts,llm}/ keep the control container completely free of livekit.plugins.* dependencies (Constitution Principle 8). All 715 tests pass.

Endpoints Implemented

  • POST /stt/transcribe: Multipart audio upload (up to 25 MB) returning JSON transcription, language, and duration. Providers: Sarvam, Cartesia, Deepgram, OpenAI, ElevenLabs.
  • POST /tts/synthesize: Text input (up to 5,000 characters) returning binary audio stream (audio/wav, audio/mpeg) with optional persistence to user audio library. Providers: Cartesia, Sarvam, ElevenLabs, Mistral.
  • POST /llm/chat: Chat messages returning standard JSON or Server-Sent Events (SSE) streaming. Providers: OpenAI, Gemini.
